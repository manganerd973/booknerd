# BOOKNERD V44 — приветствие нового читателя

## Добавлено

- готовая сценка приветствия при первом посещении с нового устройства: Тилл → Иван → Тилл → Иван;
- кнопка «Приветствие нового читателя» в редакционной, которая вставляет весь диалог в форму;
- поддержка нескольких реплик каждого персонажа: каждая новая строка в поле становится отдельной репликой;
- предпросмотр показывает точный порядок всего разговора;
- при повторном редактировании многострочная сценка не сокращается до одной реплики каждого персонажа.

## D1

- новые таблицы, колонки и миграции не добавлялись;
- встроенное приветствие работает без новой записи в D1;
- запись создаётся только один раз, если владелец сам сохранит отредактированный вариант из редакционной.
