# BOOKNERD V53 — исправление загрузки и нагрузки D1

## Что исправлено

- Страницы книг получают только компактный список глав без полных текстов.
- Читалка получает полный текст только открытой главы и больше не отрисовывает все главы в скрытом измерительном слое.
- Поиск по книге выполняется только после ввода читателя и только по доступным до открытой главы материалам.
- Офлайн-сохранение по-прежнему загружает все опубликованные главы и теперь находит изображения непосредственно в сохраняемых страницах.
- Service Worker больше не загружает 67 стикеров, главную, профиль и рейтинг при каждой установке новой версии.
- Стикеры и другие изображения кэшируются по мере использования.
- Блоки рейтинга, статистики BOOKNERD и голосования загружают данные только при приближении к области экрана.
- Сводка уведомлений и «Цитата дня» запрашиваются после первой отрисовки.
- На главной сначала показываются восемь книг; остальные открываются кнопкой «Показать ещё книги».
- Добавлена компактная метка версии схемы D1. После первого безопасного запуска новые экземпляры Worker проверяют одну строку вместо серии проверок таблиц.

## D1

V53 не копирует книги или главы и не создаёт журнал просмотров. Добавляется только одна техническая строка в таблице `app_schema`. Полные тексты глав по-прежнему находятся в существующей таблице `chapters`.

## Публикация

Архив подготовлен без публикации. Адрес сайта и настройки Cloudflare не изменялись. R2 не подключался.
