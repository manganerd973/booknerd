ПРОФИЛЬ
После установки обновления откройте свой существующий профиль → Сохранить доступ к профилю → Получить код восстановления. Скопируйте его в надёжное место ВНЕ приложения. Код является секретом: любой, у кого он есть, может открыть этот профиль. После переустановки: профиль → Вернуть прежний профиль → вставить код → Восстановить профиль.
Восстанавливается тот же серверный идентификатор и связанные данные: личная библиотека, профиль, серверная статистика. Данные разных профилей не объединяются. Офлайн-книги, локальные выделения, настройки устройства и старые голоса с отдельным локальным ключом в этот механизм не входят. Код нельзя получить задним числом после полной потери старой идентичности. Пароль владельца должен быть настроен; при его изменении ранее выданные коды перестают действовать. Для обычного удаления ярлыка данные иногда сохраняются, но полагаться на это нельзя.
Коды подписаны сервером, не создают дополнительную таблицу и не запускают фоновые запросы.
