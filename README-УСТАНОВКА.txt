BOOKNERD — обновление чтения и комментариев, 19 ноября 2026

Установка:
1. Распакуйте архив.
2. Скопируйте папки app, lib, public, src, worker и остальные файлы из архива в C:\Users\HP\Documents\GitHub\booknerd с заменой одноимённых файлов. Не удаляйте остальные файлы проекта.
3. В GitHub Desktop проверьте список изменений, нажмите Commit, затем Push origin.
4. Дождитесь успешного развёртывания Cloudflare. Закройте и снова откройте BOOKNERD. Удалять приложение, очищать данные и создавать новый профиль не нужно.

Изменения:
— «Продолжить чтение»: номер текущей главы, всего опубликованных глав, процент чтения и количество следующих глав.
— Сердечки и число комментариев в оглавлении; контрастный текст в светлой и тёмной темах.
— Обсуждения глав видны во вкладке комментариев книги. Ответ сохраняется в соответствующей главе.
— Комментарии отправляются с именем сохранённого профиля; отдельного поля псевдонима нет. Если имя не заполнено, форма направляет в профиль. Официальные ответы BOOKNERD доступны только через административный маршрут владельца.
— После главы комментарии идут перед рекомендациями.
— Wrapped удалён из закладок: пункт «Моя статистика · Wrapped» в меню профиля, фиолетовое оформление.
— Убрана строка «От лица». При первом открытии обновления включается непрерывная прокрутка. При желании другие режимы можно снова выбрать в настройках.
— Кот использует независимые слои с явными размерами, хвост анимируется. Сохранённая тема применяется до показа страницы.
— Новая иконка №4 сохранена, включая блок установки на телефон. Включены предыдущие исправления из полного архива и исправление иконки установки.

Данные и ограничения:
База данных не очищается. Изображения и главы не дублируются. Предыдущие настройки Cloudflare и ограничение загрузки изображений сохранены. Этот архив не содержит резервной копии серверной базы.
Проверены производственная сборка, серверная разметка книги, комментарии/ответы/права и SQLite-запросы. Браузерная проверка на телефоне не выполнена: Chromium в рабочей среде не запускается. Фактическую скорость Cloudflare после установки необходимо проверить на работающем сайте.
